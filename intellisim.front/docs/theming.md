# Theme & Styling Guide

This guide covers the IntelliSim frontend theming system, including PrimeVue customization, Tailwind CSS integration, and color token management.

## Design System Overview

The IntelliSim frontend uses a **dark-accented, modern design** with:

- **Primary Colors**: Zinc (grayscale) + Violet (accent)
- **Component Library**: PrimeVue (Aura preset)
- **Utility CSS**: Tailwind CSS 4
- **Color Tokens**: Semantic tokens (primary, accent, error, success, etc.)

## PrimeVue Preset

**File**: `src/shared/theme/primevue-preset.ts`

The `IntelliSimPreset` customizes the PrimeVue Aura theme with Zinc + Violet color scheme.

```typescript
import { definePreset } from '@primeuix/themes'
import Aura from '@primeuix/themes/aura'

const IntelliSimPreset = definePreset(Aura, {
  semantic: {
    primary: {
      50: '#f5f3ff',
      100: '#ede9fe',
      200: '#ddd6fe',
      300: '#c4b5fd',
      400: '#a78bfa',
      500: '#8b5cf6',      // Primary button, link color
      600: '#7c3aed',
      700: '#6d28d9',
      800: '#5b21b6',
      900: '#4c1d95',
      950: '#2e1065',
    },
    colorScheme: {
      light: {
        surface: {
          0: '#ffffff',
          50: '#fafafa',
          100: '#f4f4f5',
          200: '#e4e4e7',
          300: '#d4d4d8',
          400: '#a1a1aa',
          500: '#71717a',
          600: '#52525b',
          700: '#3f3f46',
          800: '#27272a',
          900: '#18181b',
          950: '#09090b',
        },
      },
    },
  },
})

export default IntelliSimPreset
```

### How PrimeVue Uses Presets

PrimeVue components consume these tokens:
- Buttons: background = primary.500, hover = primary.600
- Inputs: border = surface.200, background = surface.0
- Cards: background = surface.0, border = surface.200
- Links: color = primary.500, hover = primary.600

**Files Affected**:
- All PrimeVue components (Button, InputText, Dialog, etc.)
- Component styles automatically update when preset changes

## Modifying the Theme

### Change Primary Color

**Option 1: Edit Preset** (affects all PrimeVue components)

File: `src/shared/theme/primevue-preset.ts`

```typescript
const IntelliSimPreset = definePreset(Aura, {
  semantic: {
    primary: {
      50: '#fef3c7',    // Change from violet
      // ... rest of amber palette
      500: '#f59e0b',   // Amber instead of violet
    },
  },
})
```

**Option 2: Edit Color Tokens** (affects custom components)

File: `src/shared/theme/colors.ts`

```typescript
export const colors = {
  accent: '#f59e0b',       // Amber instead of violet
  accentLight: '#fbbf24',
  accentDark: '#d97706',
  // ... rest
}
```

**Result**: All buttons, links, and custom accent elements change color.

### Change Background Colors

In `primevue-preset.ts`:

```typescript
colorScheme: {
  light: {
    surface: {
      0: '#ffffff',      // White
      50: '#fafafa',     // Zinc-50
      100: '#f3f4f6',    // Gray-100 (lighter background)
      // ... adjust other levels
    },
  },
}
```

### Add Custom Colors

Option 1: Add to colors.ts (for custom components):

```typescript
export const colors = {
  // ... existing colors
  secondaryAccent: '#06b6d4',   // Cyan
  brand: '#8b5cf6',              // Your brand color
}

export type ColorToken = keyof typeof colors
```

Option 2: Add to PrimeVue preset (affects all PrimeVue components):

```typescript
const IntelliSimPreset = definePreset(Aura, {
  semantic: {
    primary: { ... },
    secondary: {
      50: '...',
      500: '#06b6d4',
      // ... full scale
    },
  },
})
```

Usage:

```vue
<Button :pt="{ root: { class: 'p-button-secondary' } }" />
```

### Variant System

Create theme variants (dark/light mode):

File: `src/shared/theme/variants.ts` (new file):

```typescript
export const lightTheme = {
  // Light background, dark text
  background: '#fafafa',
  text: '#18181b',
  surface: '#ffffff',
}

export const darkTheme = {
  // Dark background, light text
  background: '#09090b',
  text: '#fafafa',
  surface: '#27272a',
}

export type Theme = 'light' | 'dark'
```

Usage with Pinia store:

```typescript
// stores/themeStore.ts
import { defineStore } from 'pinia'
import { ref } from 'vue'

export const useThemeStore = defineStore('theme', () => {
  const currentTheme = ref<'light' | 'dark'>('light')
  
  function toggleTheme() {
    currentTheme.value = currentTheme.value === 'light' ? 'dark' : 'light'
    document.documentElement.setAttribute('data-theme', currentTheme.value)
  }
  
  return { currentTheme, toggleTheme }
})
```

## Accessibility (a11y)

### Color Contrast

All colors meet WCAG AA standards (4.5:1 for text):

- Violet-500 (#8B5CF6) on white: ✅ 7.5:1
- Zinc-500 (#71717A) on white: ✅ 5.2:1
- Zinc-900 (#18181B) on white: ✅ 18:1

### Focus States

All interactive elements have visible focus indicators:

```vue
<button class="focus:outline-2 focus:outline-offset-2 focus:outline-violet-500">
  Focusable button
</button>
```

### Reduced Motion

Respect user's motion preferences:

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## Dark Mode (Future)

Currently using light theme. To implement dark mode:

1. Create dark preset: `darkTheme.ts`
2. Add theme switcher to Sidebar
3. Store preference in localStorage
4. Apply class/data attribute to root
5. PrimeVue supports dark mode presets

Example setup:

```typescript
// main.ts
import { usePrimeVue } from 'primevue/config'

const PrimeVue = usePrimeVue()
PrimeVue.theme.set({ preset: IntelliSimPreset, options: { darkModeSelector: '[data-theme="dark"]' } })
```

## Theme Customization Best Practices

1. **Semantic Naming**: Use color function (primary, success, error) not raw colors
2. **Consistency**: Change colors in one place (preset or colors.ts)
3. **Accessibility**: Test contrast ratios after changes
4. **Documentation**: Update this guide if adding new colors
5. **Components**: Always use `class="..."` + tokens, never hardcode hex
6. **Testing**: Run `npm run build` to validate CSS generation
